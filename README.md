## 📌 About TerraWeek

**TerraWeek** is a 7-Day Terraform and DevOps learning challenge organized by **TWS Community Builders**.

The goal of this challenge is to build practical knowledge of **Infrastructure as Code (IaC)** using Terraform and gradually move from Terraform fundamentals to real-world AWS infrastructure provisioning.

During these 7 days, I explored Terraform concepts including:

- Infrastructure as Code (IaC)
- HashiCorp Configuration Language (HCL)
- Terraform Providers and Resources
- Variables and Outputs
- Data Sources and Locals
- Terraform State Management
- Remote Backend and State Locking
- Terraform Import and Drift Detection
- Reusable Terraform Modules
- Terraform Registry Modules
- Amazon EKS
- Terraform Workspaces
- Multi-Environment Infrastructure
- Real-World Terraform Capstone Project

---

# 🎯 Challenge Objective

The main objective of TerraWeek is to develop practical Terraform skills and understand how Infrastructure as Code can be used to automate and manage cloud infrastructure.

### Key Goals

- Understand Infrastructure as Code
- Learn Terraform fundamentals
- Write infrastructure using HCL
- Manage AWS resources using Terraform
- Understand Terraform state
- Work with remote state and locking
- Create reusable Terraform modules
- Provision AWS infrastructure
- Deploy an EKS cluster using Terraform
- Manage multiple environments
- Build a real-world Terraform project

# 📚 TerraWeek – 7 Day Learning Roadmap

| Day | Topics Covered |
|-----|----------------|
| **Day 01** | IaC, HCL, `init`, `plan`, `apply`, `destroy`, State Basics |
| **Day 02** | Providers, Resources, Dependencies, Lifecycle |
| **Day 03** | Variables, Outputs, Data Sources, Locals, Functions |
| **Day 04** | Remote Backend, State Locking, Import, Drift |
| **Day 05** | Custom Modules, Registry Modules, Versioning |
| **Day 06** | EKS with Modules, Real-World Provisioning |
| **Day 07** | Workspaces, Multi-Environment, Capstone Project |
